Turn images into Unicode text art. `ansi-warhol` renders every glyph in a
character palette and, for each cell of the output grid, picks the glyph whose
shape best matches that patch of the image, using WebGPU (with CPU fallback).

`ansi-warhol` can be used as a library, CLI or Web UI, including support for advanced
"image" manipulation features such as:

- **Width, font, line height**: size of the output grid and the font it is
  rendered for.
- **Distance**: how glyphs are matched to image cells (`SSIM`, `HISTOGRAM`,
  `SUM_OF_SQUARES`, `SUM_OF_ABS_DIFF`, `MINIMIZE_CROSS_CORRELATION`).
- **Brightness, contrast**: image adjustments. **Auto** searches for the
  settings that give the most varied glyph use.
- **Characters**: build the palette from Unicode blocks, or type a custom set.
  An exclude list removes characters from either.
- **Layers**: each layer has its own image, palette and settings. Higher
  layers are drawn over lower ones, and spaces are transparent. Drag to
  reorder, use the checkbox to show or hide, and double-click a name to rename.
- **Crop**: click *Select Region* and drag over the output to limit the
  selected layer to an area. Hold Shift to add to the region, or Alt/⌘ to
  remove from it.
- **Color**: per layer, colour each glyph so its cell, as displayed (glyph
  ink plus the background showing through, including line-height leading),
  averages to the image's colour there. Brightness, contrast and *Invert
  Image* only steer glyph choice; colours always come from the original image.
- **Export**: *Copy* puts plain text (and coloured HTML, when colour is on) on
  the clipboard. *Save* writes plain text (`.txt`), ANSI 24-bit colour
  (`.ans`) or a standalone HTML page (`.html`).


## Getting started

```bash
npm install
npm run build
```

`canvas` is a native dependency. If its install fails, see the
[node-canvas build instructions](https://github.com/Automattic/node-canvas#compiling).

## Web app

```bash
npm run build
npm run serve
```

This serves the built app from `dist/`. Open the URL `serve` prints, choose
an image, and adjust the controls.

## CLI

The package installs an `ansi-warhol` shell command. From a checkout, build
and link it onto your `PATH`:

```bash
npm run build
npm link
```

```bash
ansi-warhol [--width <n>] [--distance <fn>] [--evaluate <fn>] [--out <file>] [--color] <image.png>
```

This converts a PNG, auto-fitting brightness and contrast, and writes the
result to `out.txt` (or `out_1.txt`, `out_2.txt`, … if those exist). With
`--color` it writes ANSI 24-bit colour to `out.ans` instead; view it with
`cat out.ans` in a truecolor terminal. The image
path must come last. Run `ansi-warhol --help` for all options, or
`./bin/ansi-warhol` to run it without linking.

## Library

```ts
import { pngToAscii, browserCanvasFactory } from "ansi-warhol";

const { ascii, stats } = pngToAscii(
	imageData, // anything with width, height and RGBA data
	100, // output width in characters
	browserCanvasFactory,
	"SSIM",
);
```

`estimateAscii` is a generator that runs the same conversion while searching
for the best brightness and contrast. `WebGPURenderer` offers both on the GPU.
